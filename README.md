# Devendra Singh Portfolio

A static HTML, CSS, and JavaScript portfolio site using Bootstrap 5.3 for responsive layout support.

## Run locally

Open `index.html` directly in a browser. No backend is required because the portfolio content is static.

## Deploy with GitHub Pages

1. Create a GitHub repository and upload every file in this folder.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.

## Deploy with Netlify

1. Sign in to Netlify and choose **Add new site → Import an existing project**.
2. Connect the GitHub repository.
3. Leave the build command empty and set the publish directory to `/`.
4. Deploy the site.

The supplied resume and certificates are kept in the project root so their download links continue to work after deployment.
